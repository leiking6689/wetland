# 湿地 Wetland · 白鹤与鄱阳湖（交互式课件网页）

上海金山杭州湾双语学校 · G9 Honor Biology（AP 方向）· W3 教学网页
由《W3 湿地》PPT 课件转化而来，**保留课件原有视频与图片**，可直接在浏览器中交互授课。

## 打开方式

- **本地授课**：双击 `index.html` 即可（Chrome / Edge / Safari 均可），无需联网；视频为本地文件 `assets/crane.mp4`。
- **GitHub Pages 部署**：把本文件夹全部内容推送到仓库根目录（或 `/docs`），在 Settings → Pages 选择对应分支即可。`.nojekyll` 已包含，资源路径均为相对路径。

## 目录结构

```
wetland-site/
├── index.html        # 课件网页（内联 CSS/JS，无外部依赖）
├── .nojekyll         # GitHub Pages 配置
```

## 7 个教学环节

1. **白鹤的故事**：飞行视频 + 资料卡 + 头脑风暴 + 鸟类飞行/羊膜卵小测验
2. **鄱阳湖的"呼吸"**：冬夏水位切换 SVG 动画 + 南昌逐月降水柱状图/气温曲线 + 卫星与落星墩对照 + 气候填空
3. **重点① 水位 × 种群**：论文片段批注（7 处可点击高亮）→ 因果链顺序点亮 → 30 年种群交互折线（悬停 tooltip）
4. **重点② 食物之变**：70 份粪便食谱数据条形动画 + 食物调查图 + 三条推断讨论
5. **大坝之辩**：12 个影响因素自然/人为分类 + 鄱阳湖水利枢纽正反双方 + 时间线 + 班级投票
6. **湿地修复**：六大生态系统服务 + 条子泥"720 亩"成功案例 + 连云港蓝湾"伪修复"案例（时间线 + 五条深层原因）
7. **如何研究**：科学探究六步 + 学生研究设计任务 + 本校"扬帆启杭"队鹦鹉洲宏基因组完整案例（含外链）
